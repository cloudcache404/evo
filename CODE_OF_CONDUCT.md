# Code of Conduct

## Our Standard

We want EvoBot to be a welcoming project for developers of all
experience levels.

Contributors are expected to:

- Be respectful
- Be constructive
- Avoid harassment
- Avoid personal attacks
- Respect different opinions
- Keep discussions focused on the project

Unacceptable behavior will not be tolerated.

## Enforcement

Project maintainers may remove comments, close issues,
or take other appropriate action when this code of conduct
is violated.
