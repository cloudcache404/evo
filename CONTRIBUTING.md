# Contributing to EvoBot

Thanks for your interest in contributing! 🚀

EvoBot is an open-source project and contributions are welcome.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch.
4. Install dependencies.
5. Make your changes.
6. Test your changes.
7. Open a Pull Request.

## Branch Naming

Use descriptive branch names:

# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in EvoBot,
please do not publicly disclose it through a GitHub issue.

Contact the project maintainers privately.

## Never Share Secrets

Do not publish:

- Telegram bot tokens
- AI API keys
- Database credentials
- Admin credentials
- Private configuration

## Exposed Credentials

If a credential is accidentally committed:

1. Revoke it immediately.
2. Generate a replacement.
3. Remove the secret from the repository.
4. Review Git history if necessary.

Thank you for helping keep EvoBot secure. 🔐
